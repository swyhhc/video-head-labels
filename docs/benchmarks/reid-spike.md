# Task 8：轻量 Appearance Spike

日期：2026-09-11

## 结论

采用无模型的轻量 appearance descriptor，不引入独立 ReID ONNX 模型。

描述子由以下信息组成：

- 检测框内 2 × 2 空间分块
- 每个分块的 HSV 分量直方图
- 检测框长宽比
- 共 65 个归一化数值

Track 使用 EMA 聚合历史描述子，默认更新系数为 `0.25`。最终匹配成本保留类别、IoU、中心距离、速度趋势和 Hungarian 全局分配；appearance 权重为 `0.45`。空间距离仍是硬限制，外观相似不能覆盖明显不合理的位置。

## 为什么不增加模型

OSNet 等轻量 ReID 网络适合人物，但本产品还需要鸟、汽车等通用类别。可找到的预训练权重大多依赖特定人物数据集，权重授权与 ONNX 发布来源也不够统一；额外模型还会增加下载、初始化和浏览器内存成本。

当前方案不增加模型文件、运行时或第三方许可证。它对颜色或空间外观明显不同的同类主体有效，并保持实现简单可维护。

## 性能

真实视频：本地 10 秒 MP4，21 个检测抽样帧，16 个有效 descriptor。

| 指标 | 结果 |
|---|---:|
| Appearance 总耗时 | 1.40 ms |
| 每个抽样帧平均耗时 | 0.067 ms |
| 单个 detection 平均额外耗时 | 0.088 ms |
| 单个抽样帧最慢耗时 | 0.50 ms |
| 10 个主体合成像素基准 | 0.155 ms / 抽样帧 |
| 新增模型大小 | 0 |

真实视频的 descriptor 在现有 Detection Worker 中计算，直接复用 YOLO 预处理已经读取的 640 × 640 RGBA 像素。每个检测框最多采样 32 × 32 个像素，不创建额外裁剪画布，不把图片存入 Track。按 10 个主体、21 个抽样帧估算，描述子纯数值约 107 KB，不含 JavaScript 对象开销。

## Before / After

有明确身份标注的测试数据覆盖两人交叉、两只同类动物交叉和短暂漏检后返回：

| 场景 | Motion only | Motion + appearance |
|---|---:|---:|
| 两人靠近后反向 | 2 次身份交换 | 0 |
| 两只同类动物靠近后反向 | 2 次身份交换 | 0 |
| 短暂漏检后在另一主体附近返回 | 2 次错误关联 | 0 |

真实 10 秒样本本身没有出现可观察的交叉冲突：Before 与 After 都产生 8 条 Track，appearance 连续性异常均为 0，分配差异为 0。因此真实样本证明的是“没有退化和额外成本很低”，改善证据来自具有已知身份的针对性测试数据。

## Worker 与回退

- Appearance 只在检测抽样帧计算。
- 计算发生在现有 Detection Worker，不回到 React 主线程。
- 每帧只为置信度排序靠前的最多 10 个检测生成 descriptor。
- descriptor 缺失或长度不一致时，Tracker 自动使用原有 motion-only 成本。
- 类别不一致与空间距离过大仍禁止匹配。

## 已知限制

- 颜色接近、穿着相同或外观被背景主导时，描述子的区分能力有限。
- 光照剧烈变化、强运动模糊和大面积遮挡仍可能导致身份交换。
- 这不是学术级人物 ReID，也不处理跨镜头身份恢复。
- 当前没有人工合并、拆分或身份纠错能力。
