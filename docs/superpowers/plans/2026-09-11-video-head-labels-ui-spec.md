# 视频头顶加字幕 — V1 UI / UX 约束

日期：2026-09-11
状态：已确认
项目：video-head-labels

## 1. 视觉方向

整体采用：

> 极简、轻量、专业，但不做传统专业剪辑软件的沉重感。

气质参考：
- Apple 系工具
- Linear / Arc 一类轻量产品
- 简化版视频编辑器

核心原则：

> 视频是主角，AI 和编辑工具安静地服务于视频。

## 2. 设计原则

- 视频预览区是整个编辑器的视觉中心。
- 初次进入只展示上传；上传后再进入编辑器。
- 分析开始后再逐步出现主体、时间轴和编辑能力。
- 主界面使用普通用户语言，不显示 Track ID、IoU、Embedding、ReID Distance 等工程术语。
- 工程信息仅允许进入 Debug 模式。

## 3. 色彩系统

页面背景：`#F7F7F5`  
主面板：`#FFFFFF`  
主文字：`#171717`  
次级文字：`#777777`  
弱文字：`#A3A3A3`  
边框：`#E8E8E5`  
Hover / 弱背景：`#F1F1EF`  
主强调色：`#6ED3CF`  
成功：`#27A36A`  
警告：`#D98B2B`  
错误：`#D94A4A`

### 主强调色使用规则

`#6ED3CF` 仅用于：
- 主按钮
- 当前选中主体
- 进度状态
- 焦点状态
- 时间轴高亮
- 选中轮廓 / 小型定位元素

禁止大面积铺满整个页面。

## 4. 圆角与阴影

小控件：8px  
按钮：10px  
普通卡片：12px  
大面板：16px  
上传区域：20px

阴影规则：
- 默认不用重阴影。
- 主要依靠背景层级 + 1px 边框。
- 弹窗、下拉菜单、浮层可以使用轻阴影。

禁止：
- 大面积浮夸阴影
- 玻璃拟态
- 发光边框
- 渐变背景

## 5. 字体

优先系统字体：

```css
font-family:
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  sans-serif;
```

字号建议：
- 页面标题：24–28px
- 区域标题：16–18px
- 正文：14px
- 辅助文字：12–13px
- 按钮：14px

避免大面积 Bold。

## 6. 首屏 / 空状态

初次进入不展示复杂编辑器。

内容：

```text
视频头顶加字幕

给视频里的任何东西
加一个会跟着它走的名字。

[ 上传视频 ]

视频仅在你的设备上处理，不会上传服务器

MP4 / MOV · 推荐 15 秒以内 · 最高 1080p
```

上传支持：
- 点击选择文件
- 拖拽上传

上传区域使用大卡片，但不做密集传统虚线框。

## 7. 桌面编辑器布局

```text
┌──────────────────────────────────────────────┐
│ Header                                       │
├───────────────────────────────┬──────────────┤
│                               │              │
│                               │ 主体面板     │
│         视频预览区             │              │
│                               │              │
│                               │              │
├───────────────────────────────┴──────────────┤
│                  时间轴                      │
└──────────────────────────────────────────────┘
```

建议：
- 右侧面板：280–320px
- 时间轴：100–140px
- 其余空间优先留给视频

## 8. Header

左侧：
- 视频头顶加字幕
- 可选小状态：“仅本地处理”

右侧：
- 重新上传
- 导出视频

“导出视频”是唯一明显主按钮，使用 `#6ED3CF`。

不要添加：
- 复杂导航
- 登录
- 用户头像
- 设置中心
- 营销链接

## 9. 视频预览区

背景：`#ECECEA` 或接近的浅灰。

规则：
- 视频居中。
- 始终 `contain`，不裁切。
- 支持横屏、竖屏、方形。
- 四周留呼吸空间。

视频上叠加：
- 动态标签
- 引导线

仅编辑模式显示：
- 检测框
- 选中状态
- 调试轨迹

最终导出不显示调试信息。

## 10. 主体选中状态

使用：
- 1–1.5px 细描边
- `#6ED3CF`
- 四角小定位标记
- 标签轻微增强亮度

右侧对应主体卡片同步高亮。

## 11. 动态标签视觉

默认结构：

```text
麻雀
Tree Sparrow
    │
    │
```

规则：
- 中文为主标题
- 英文为副标题
- 英文大小约为中文的 45%–55%
- 白色文字
- 英文约 85% 透明度
- 引导线约 70% 透明度
- 允许非常轻微阴影 / 描边确保复杂背景可读

禁止：
- 彩色标签底板
- 大黑底
- 厚描边
- 发光
- Emoji
- 卡通贴纸

目标：
> 标签像自然存在于现实画面中。

## 12. 主体面板

标题：`主体`

列表项示例：

```text
麻雀 01
Tree Sparrow

[显示/隐藏]  [进入编辑]
```

选中后展开：
- 名称（中文）
- 名称（英文）
- 样式
- 显示 / 隐藏
- 重新指定主体

AI 原始类别弱化显示，例如：
`识别为 Bird · 92%`

## 13. 标签预设

V1 仅提供 3 个：

### 经典
中文 + 英文 + 引导线

### 极简
仅中文

### 数据感
中文 + 英文 + 类别 / 置信度

默认：经典

## 14. AI 分析状态

上传后不要弹重型 Modal。

在编辑器中显示轻量分析状态：

```text
正在分析视频…

正在寻找主体
████████░░ 78%

已找到 4 个主体
```

辅助文案：
`正在本地处理，视频不会上传`

## 15. 时间轴

V1 时间轴必须简洁。

```text
00:00 ━━━━━━━━━●━━━━━━━━ 00:15
```

Track 存在区间：

```text
麻雀 01   ━━━━━━━━━━━━━
麻雀 02       ━━━━━━━━━
人 01              ━━━━━
```

人工修正节点使用小菱形 / 小点。

不做：
- 多轨剪辑
- 音频波形
- 复杂剪切工具
- 专业 NLE 轨道

## 16. 纠错文案

允许：
- 跟错了
- 身份错了
- 重新指定主体
- 从这里开始跟这个
- 请选择正确的主体

禁止：
- 重新关联 Track ID
- ID Switch Correction
- Rebind Track
- ReID Match

## 17. 未识别主体

使用：

```text
没有找到明显的主体

你可以直接点击视频里的东西，
告诉我你想跟踪谁。

[ 手动选择主体 ]
```

必须永远给用户下一步。

## 18. 导出面板

使用右侧轻量面板，不使用大弹窗。

```text
导出视频

格式
MP4

分辨率
原始

标签
经典

所有处理均在本机完成

[ 导出 MP4 ]
```

导出中：

```text
正在制作视频

██████████░░ 72%

请保持页面打开
```

## 19. 动效规范

普通 UI 动效：`150–220ms`

允许：
- 面板展开
- 选中状态
- 按钮反馈
- 标签出现
- 进度变化

禁止：
- 弹跳
- 大幅缩放
- 旋转
- 花哨转场
- 无意义动效

## 20. 响应式预留

桌面优先，大屏完整布局：`>= 1200px`

未来手机端：
- 视频在上
- 时间轴在下
- 主体编辑改为 Bottom Sheet / 抽屉

硬规则：
- 所有关键操作必须支持点击 / 触控
- 禁止关键能力只存在于 hover
- Canvas 坐标必须基于原视频坐标，不基于屏幕像素

## 21. Task 1 的 UI 范围

Task 1 只允许实现：

1. 空状态上传页
2. 视频上传
3. 进入基础编辑器
4. 视频主区域
5. 右侧主体面板占位
6. 底部时间轴占位
7. Header + 重新上传 / 导出按钮占位

不得在 Task 1：
- 添加假 AI 结果
- 添加假主体
- 添加复杂时间轴能力
- 添加 ffmpeg
- 添加 ONNX
- 添加 YOLO
- 添加真实导出功能

## 22. 禁止事项

Codex 实现时明确禁止：

- 渐变背景
- 玻璃拟态
- 大量阴影
- 霓虹色
- 深色专业剪辑器风格
- Hero 大图
- 营销官网结构
- 登录 / 注册
- 顶部复杂导航
- 大量 Emoji
- 自行增加功能
- 大面积使用主强调色
- 自行更换主色 `#6ED3CF`

## 24. 最终 UI 原则

> 这个产品应该看起来像一个“打开就会用”的轻量工具，而不是专业视频软件。视频是主角，AI 和编辑工具都应该安静地服务于视频。
